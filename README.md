# School-database-using-Postgres
A postgreSQL database schema and queries for managing school operations.

## Project Overview
This project contains the SQL scripts built for Greenwood Academy, a secondary school based in Nairobi. It covers setting up the database structure, inserting data records, and running data analysis queries.

## Folder Structure
The project is organized into separate files for easy navigation:
- `README.md` - Project details and information page.
- `section_a_ddl.sql` - Creating schemas, tables, and altering table structures.
- `section_b_dml.sql` - Adding data rows, updating records, and deleting records.
- `section_c_query.sql` - Basic data filtering using WHERE conditions.
- `section_d_operators.sql` - Advanced filtering using BETWEEN, IN, and LIKE operators.
- `section_e_count.sql` - Data aggregation queries using the COUNT function.
- `section_f_case_when.sql` - Conditional logic grading and student categorization.
